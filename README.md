# Kather Ghani (KG) – Logo

Logo for **Kather Ghani**, oil products company. Uses initials **KG** with a green and gold palette and a small oil-droplet accent.

## Files

| File | Use |
|------|-----|
| `logo.svg` | Square logo: **Facebook profile picture**, favicon, app icon |
| `logo-website.svg` | Horizontal logo with “Kather Ghani” and “Premium Oil”: **website header** |
| `index.html` | Preview page and **“Download PNG for Facebook”** (180×180) |

## Facebook profile

1. Open `index.html` in your browser.
2. Click **“Download PNG for Facebook (180×180)”**.
3. Upload the downloaded `kather-ghani-facebook-profile.png` as your Facebook page profile picture.

Or use `logo.svg` directly if the platform supports SVG; otherwise use the PNG from the button.

## Website

- **Header / navbar:** Use `logo-website.svg` (full “Kather Ghani” + “Premium Oil”).
- **Favicon / app icon:** Use `logo.svg`; convert to ICO or PNG (e.g. 32×32, 180×180) with any favicon generator or image editor.

## Colors

- Green: `#1a3d32` / `#2d5a4a`
- Gold: `#B8860B` / `#E8C547`
- Light text on green: `#F5F5DC`
